# Monetized Brand Builder

Upload everything in this folder to the root of your repo: index.html, script.js, robots.txt, sitemap.xml and the images folder.
Form responses go through Web3Forms. Bookings go through the embedded Google Calendar booking page.
The search setup assumes the domain https://monetizedbrandbuilder.com. If you use a different domain, find and replace it in index.html, robots.txt and sitemap.xml.
